# V9 design research notes

The layer is informed by current construction/corporate patterns:
- Shapoorji Pallonji prominently connects HSE, CSR, people, technology, legacy and project search. See: https://shapoorji.in/
- Turner connects careers, ESG, community, innovation, safety and project portfolio content. See: https://www.turnerconstruction.com/careers and https://www.turnerconstruction.com/
- Afcons presents careers through functions, lifecycle experience, culture and future-facing capability building. See: https://afcons.com/career/
- Turner’s innovation content explicitly discusses emerging digital workflows, AI, automation and connectivity; V9 uses this as an inspiration for a cautious “learning and expanding techniques” layer, not as a claim that Miror already deploys these technologies. See: https://www.turnerconstruction.com/commitments/innovation
- Tata Projects career IA provides job search by location, experience, function and sector; V9 reserves similar extensibility without publishing unconfirmed openings. See: https://careers.tataprojects.com/

Design synthesis for Miror:
1. Project-first navigation remains inherited from V8.
2. V9 adds corporate depth and business-development trust.
3. Technical/CAD language remains subtle; not every section receives 3D.
4. “Coming soon” states are intentional, not blank content.
5. Every public claim should be client-approved before publication.
