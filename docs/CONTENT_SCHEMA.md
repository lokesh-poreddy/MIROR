# Miror project data intake

For each of the ~18 projects, ask the client for:

- project_name
- category
- location
- state
- country
- start_year
- completion_year
- project_status
- client_name
- principal_contractor
- Miror_role
- scope_summary
- scope_items
- project_value (optional, publish only with approval)
- measurable_metrics (optional, evidence required)
- description
- cover_image
- gallery_images
- video_url (optional)
- before_after_media (optional)
- methods_or_systems (only if documented)
- permission_to_publish
- source_document or internal confirmation
- featured
- seo_title
- seo_description

Never invent client names, values, dates, awards, certifications, safety statistics or performance claims.
