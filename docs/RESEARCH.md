# Design research implementation baseline

The design system should synthesize patterns from leading construction, infrastructure, corporate, technology and premium digital-product websites without cloning them.

High-value patterns:
- persistent, low-noise global navigation
- full-screen menu for secondary navigation
- cinematic project photography with restrained overlay typography
- project grids with deliberate asymmetry
- project detail routes with metadata and scope
- capabilities ↔ projects cross-linking
- evidence-led trust sections
- subtle scroll reveals
- clear enquiry CTA
- strong footer/contact architecture
- responsive mobile menu and progressive motion

Avoid generic construction-site tropes, fake metrics, unsupported client logos, excessive gradients/glass, auto-playing audio, long loading screens and unnecessary WebGL.
